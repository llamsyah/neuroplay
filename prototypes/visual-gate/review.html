  3. Explorer: compare unselected and selected views. Read identity → explanation → relevant actions → optional sources. Open Pilih bagian lain to switch, then use Pilihan sebelumnya. Whole-brain restoration and homepage return are distinct controls.
  4. Hippocampus: choose it in the Explorer menu, reveal it deliberately, switch sides, isolate, and restore. These controls do not appear for surface gyri. Previous selection can return to the earlier surface region.
