Seret untuk memutar. Klik bagian untuk mengenalinya.

Gunakan tombol panah untuk memutar, plus dan minus untuk zoom, nol untuk mengatur ulang. Daftar anatomi menyediakan pilihan tanpa perlu menunjuk model. Pada layar sentuh, ketuk untuk memilih; aktifkan putar untuk menyeret model.

Anatomi sebagai dasar.

Model asli HRA Brain Male v1.3, Kristen Browne & Heidi Schlehlein / HuBMAP (2023). Geometri dan hubungan antarstruktur dipertahankan. Penyesuaian tampilan meliputi skala seragam, pemusatan seluruh model, material, pencahayaan, dan visibilitas.

Enam pilihan permukaan dicocokkan dengan nama mesh, label, ID ontologi, dan crosswalk penerbit. Hipokampus memakai enam mesh bernama eksplisit; ID ontologinya belum tersedia. Ini bukan sertifikasi independen atas segmentasi anatomi.

Atlas ini menggunakan pencerminan satu hemisfer dan bukan pemindaian individu. Transparansi bersifat ilustratif.
